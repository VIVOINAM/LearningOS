# l-os-code

在库里直接读课程文件夹里的 MATLAB `.m` 脚本。

Obsidian 不认 `.m`，点链接会交给系统默认程序。本插件把 `.m` 登记给一个只读视图：等宽、行号、MATLAB 着色、`%%` 分节横线，长行在代码缩进处折行。页头三个按钮：复制全部代码、用系统默认程序打开、折行开关（命令「代码：长行折行（开 / 关）」同一个开关）。

## 对外接口

没有。它不调别的插件，别的插件也不调它。课程主页里「关联代码」那一节是 l-os-workbench 写的普通 wikilink；本插件停用时链接还在，点下去回到 Obsidian 的默认行为。

## 为什么自己写着色

Obsidian 的 ```` ```matlab ```` 走 Prism，它分不清转置 `A'` 和字符串开头，`x = A'; s = 'abc';` 会把中间一段染成字符串；它也不认 `%{ … %}` 块注释和 `%%` 分节。`core/matlab.js` 是一个逐行扫描器：

- `'` 紧贴在名字、数字、右括号、另一个转置后面是转置，否则是字符串；`''` 是转义。
- `%{`、`%}` 独占一行才是块注释边界，可以嵌套；`%%` 开头的行是分节。
- `...` 之后到行尾是注释。结构体字段 `s.end` 不是关键字。
- 着色只切分不改写：每行的记号拼回去等于原行。测试对课程文件夹里每一个真实 `.m` 验证这一点，并要求不出现没闭合的字符串。
