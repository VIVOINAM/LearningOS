# L-OS 学习 · V5.6.5

打开 Vault 内的 PDF 即显示知识卡片抽屉。

- 阅读时直接选中文字，选区上方出现「高亮／批注／复制文字引用」。
- 点击 PDF 内的章节、公式或参考文献链接后，可用学习面板顶部的 `←` / `→` 回到跳转前的位置或再次前进；历史保留页码、缩放与页内偏移。命令面板中也提供「PDF 返回跳转前的位置」与「PDF 前进到下一个跳转位置」，可自行绑定快捷键或鼠标侧键。普通滚动不会写入跳转历史。
- 按住 **Alt 拖拽** 框选公式；也可执行命令「框选 PDF 公式」，再次执行或 Esc 取消。
- 框选后可「复制双链引用」或「保存到侧栏笔记」，批注可留空。
- 拖拽卡片到 Markdown **编辑区**插入完整引用；点击卡片回跳 PDF 区域。
- 「附近笔记」当前页始终居中：翻页时本页笔记被推到面板正中（开头几页则停在最顶上，上方不留空），上一页在上半、下一页在下半；本页没笔记就对准它该在的那道缝。
- 右栏有「附近笔记」与「公式速记」两个视图，选中哪个一直听手动的，翻页不抢。公式速记里粘贴讲义或 AI 回答：行内的 `\( \)` 与独占一行的 `\[ \]` 自动换成 Obsidian 的 `$`、`$$`，整段当场排版；也可以接着打字。确认后存成当页卡片，和截图、摘录同一份存储与导出路径。
- 侧栏卡片：默认显示当前页 ±2 页，按页分组、页标题吸顶，其余折叠在「本书其他笔记」；引文与批注分开排版；截图常驻缩略图；动作悬停显现；疑问卡片可直接标记已解决。
- 搜索覆盖正文、说明、分类、标签与 LaTeX；搜索框下有颜色筛选点与「疑问」开关；上下方向键在卡片间移动。
- Markdown 阅读模式中的区域链接及紧邻链接的截图支持回跳；纯源码文本不是可点击图片。
- 顶部 `···` 提供导出、打开教材笔记、清空与收起。清空需要确认，保留截图文件以免破坏已粘贴引用。
- 命令「沉浸阅读」隐藏侧栏、标签页头、状态栏与 ribbon，收起学习面板，当前页以外降透明度；再执行一次全部复原。默认不绑快捷键，在 Obsidian 快捷键设置里搜「沉浸阅读」自行指定。

切片和元数据存放在当前 Vault 的 `03 知识库/教材切片/`。旧插件 `data.json` 只用于首次迁移，不删除。教材笔记原有自由笔记区保留。

引用使用方式 A，例如：

```markdown
![[03 知识库/教材切片/课本_p38_crop_唯一编号.png]] [[数学/课本.pdf#page=38&studyRect=0.1,0.2,0.5,0.12|第38页跳转]]
```

`studyRect` 为页面左上角起算的归一化 x、y、宽、高，由本插件解释；不是 PDF 原生 `rect` 坐标。禁用本插件后，图片和标准页码链接仍可使用，但区域高亮不可用。坐标支持缩放；截取后请保持页面旋转方向不变。

优先复用 Obsidian 内置 PDF.js 的 PDFPage 在内存中以至少 144 dpi 重绘选区；无法获得 PDFPage 时，按当前 Canvas 原始像素裁剪。单次截图限制 3200 万像素。插件不下载 PDF.js、不调用网络 API、不引入运行时第三方包，也不使用 Node 文件系统。此保证针对 l-os-study；其他插件（例如工作台天气）不属于该插件的网络边界。

工程保留原有 JavaScript 引擎，V5.2 新模块使用 TypeScript：

- `core/pdf-overlay.ts`：框选、文字浮条、高清裁剪和区域定位。
- `core/view-panel.ts`：卡片抽屉与原生 text/plain 拖放。
- `core/storage-manager.ts`：Vault 路径验证、图片与元数据保存。
- `core/reference-navigation.ts`：Markdown 引用回跳。
- `core/immersive.js`：沉浸阅读的 class 开关与当前页聚焦，纯函数，不碰数据。
- `core/card-list.js`：卡片筛选、排序与标题回退的纯逻辑。
- `core/formula-model.js`：粘贴文本 → Obsidian Markdown（只翻译定界符）。
- `core/formula-pad.ts`：右栏速记板，粘贴翻译、整段 Markdown 渲染、存卡片。
- `core/markdown-render.js`：侧栏、卡片与批注弹窗共用的 Markdown 渲染（用 Obsidian 自己的渲染器）。

在上级开发目录使用 Node 22.13+（本次验证为 Node 26.3）离线构建，无须 npm install：

```powershell
node tools/verify.js --plugin l-os-study
node tools/audit-study-v52.cjs
node tools/visual-v52.cjs
node tools/native-pdf-v52.cjs
node tools/deploy.js --plugin l-os-study
```

浏览器测试依赖本机已有 Playwright 与 Edge，可通过 `PLAYWRIGHT_PATH` 指定 Playwright。原生 PDF 测试使用工作区已有 PDF.js 和教材文件。构建器去除 TypeScript 类型，不执行完整 tsc 类型检查。

已验证 72 项单元测试、生命周期迁移/重载、离线浏览器拖放与点击、真实 PDF.js 文字层/高清裁剪/缩放。尚未在正在运行的 Obsidian 桌面窗口中完成端到端验收；其内部 PDF 包装接口变化时会提示不支持。安装后重新加载插件或重启 Obsidian 生效。

## 快捷公式注记

默认快捷键 **Z**（单键，无修饰键），命令名「快速记下公式（选区截图／点击框选）」。只在当前标签页是已挂载学习面板的 PDF 时生效；焦点在搜索框或任何输入框里时让开，照常打字。

- 已选中同一页的公式文字：自动合并选区并加小边距，保存清晰原图，不转为字母文本。
- 没有选区：点击带完整边框的公式尝试自动框选；无边框公式直接拖框，松开自动保存。
- 不弹保存方式菜单，不自动展开右侧抽屉。Esc 或再次按快捷键取消待框选状态。
- 自动边框检测不是公式 OCR；不能保证识别无边框公式的边界。选区截图请包含完整上下标和分式。
- 可在 Obsidian「快捷键」中搜索上述命令修改键位。
