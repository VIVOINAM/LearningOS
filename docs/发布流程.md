# 发布流程

> 活文档：改了脚本就改这里。

## 发一个版本

```bash
node tools/release.js 6.0.1
```

一条命令做完七件事，任何一步失败就停在那里，不会留下半个版本：

1. 工作区必须干净，当前分支必须没有未提交改动
2. `CHANGELOG.md` 顶部必须就是这个版本的小节，条目的模块名必须在 `tools/modules.js` 里
3. 写 `version.json` 与 `package.json`，并给 CHANGELOG 的小节补上日期
4. `node tools/verify.js`（test → build --stage → check --stage → smoke）
5. 构建并部署到 `.obsidian/plugins/`
6. 由 `CHANGELOG.md` 生成 `00 工作台/版本迭代.md`
7. `git commit` 并打 `v6.0.1` 的 tag

预检不落盘：

```bash
node tools/release.js --dry-run 6.0.1
```

第 7 步是整件事的落点。在 6.0 之前，版本号只存在于 manifest 和 markdown 里——34 个版本号对应 11 个 commit、4 个 tag，最新的 tag 停在 v4.0.0，5.3 到 5.6.5 在 git 里根本不存在，「回滚到 5.4.0」做不到。现在每个版本号都指向一个 git 对象：

```bash
git checkout v6.0.0 && node tools/deploy.js
```

## 版本号怎么定

七个插件锁步同一个版本，唯一来源是 `version.json`。

| 段 | 什么时候进 |
| --- | --- |
| major | 数据格式变更、需要迁移，或推翻已有的交互契约 |
| minor | 新增能力，或改变已有交互的行为 |
| patch | 修 bug、调样式、纯内部重构 |

反面参照：study 5.6.2 让 `latex` 字段退役并写了迁移，按这张表该进 major，当时只是个 patch；workbench 5.4.2 改了状态栏按钮的行为语义，该进 minor。历史版本号保留原样不追认，但从 6.0.0 起按这张表走。

## CHANGELOG 怎么写

唯一的源是根 `CHANGELOG.md`，按模块分节：

```md
## 6.0.1 · 2026-09-21

### 工作台

- ……

### 学习

- ……
```

模块名见 `tools/modules.js`。不属于任何单个模块的条目直接写在版本小节下，不加 `###`。

写法：

- 一条 = 一件用户能察觉的事。内部重构没有可察觉的变化就不写，或者合并成一条「代码清理」。
- 修 bug 要写清**原来错在哪**，不能只写「修复 XXX」。半年后回来读，有用的只有这部分。
- 做了取舍的写明为什么选这边。范本：study 5.6.4 的「上方不再留空，这比为了精确对中而空出半屏好看」。
- 不写「优化」「提升」「完善」这类没有信息量的词。
- 数据格式变更单独一条，并写明迁移是否幂等。

`00 工作台/版本迭代.md` 是它的产物，整篇生成，手改会在下次部署时被覆盖。

## 日常命令

```bash
node tools/verify.js                        # 全量检查，不落盘
node tools/verify.js --plugin l-os-recall  # 只验一个插件
node tools/deploy.js                        # 构建、部署、生成版本迭代.md
node tools/sync-docs.js                     # 只同步使用说明，不碰插件与 data.json
```

部署只复制 `main.js`、`manifest.json`、`styles.css`，不会覆盖 `data.json`。部署完在 Obsidian 里按 `Ctrl+R`。

## 出了问题

- `[错误] 源码 manifest 不应带 version` —— 版本号唯一来源是 `version.json`，把 manifest 里那行删掉。
- `[错误] CHANGELOG.md 缺少 X 的小节` —— 升了版本号但没写条目。写了再发。
- `[错误] CHANGELOG.md 出现未知模块名` —— `###` 后面的名字要在 `tools/modules.js` 里，别自己造。
- `[错误] X/CHANGELOG.md 应已合并进根 CHANGELOG.md` —— 插件目录下不再有各自的日志。
- 退回上一个版本：`git checkout v<上个版本> && node tools/deploy.js`。
