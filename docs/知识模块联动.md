# 知识地图、周五自测与学习成果

三个导航入口：「知识地图」看一门课的概念怎么搭起来、哪里薄弱；「周五自测」每周测一次，把结果写回地图；「学习成果」用精简笔记唤起记忆。原课堂笔记继续由「总结笔记」按日期集中展示。

## 分工：谁写什么

| 文件 | 谁写 | 插件怎么用 |
| --- | --- | --- |
| `03 知识库/知识地图/<代码 课程名>.json` | agent，从课堂笔记整理 | 只读，渲染导图和列表 |
| `03 知识库/周五自测/<ISO 周>.json` | agent，用户周五手动让它出题 | 只读，作答与判分 |
| `03 知识库/周五自测/<ISO 周> 作答.json` | 插件 | 每答一题追加一条 |
| `03 知识库/知识地图/掌握度.json` | 插件 | 只追加：自测结果、手动修改、迁移 |

知识数据不再放 `data.json`：Obsidian 运行时会整份覆盖它，agent 从外面写进去会被冲掉。`data.json` 里只留界面偏好（`knowledgeView`：每门课用导图还是列表、导图里展开了哪些章）。

agent 写图谱和题库的规则在 [知识图谱与出题规范](知识图谱与出题规范.md)，写完跑 `tools/check-knowledge-graph.cjs` 与 `tools/check-quiz.cjs`；校验不过的文件插件拒绝加载，并在页面上列出原因。判分和换算全部离线，不调用任何 AI。

## 知识地图

**概念图谱**：一门课分章，章下是概念——「能单独出题考」的单位，静力学三次课整理出 20 个。每个概念有固定 ID、一句话摘要、照抄自原文的关键公式、要点、先修 / 相关、课堂来源和挂在它下面的例题。学期初按大纲把没讲的章也铺上（状态 `planned`），地图从一张灰色骨架慢慢长满。

**概念 ID 固定**：旧版（7.4）的键是「课程代码 + 小写标题」，标题一改就脱钩。图谱里改名只改 `title`，删除改为 `retired: true`；`legacyKeys` 记着旧键，学习成果 frontmatter 里存的旧键经它映射到新概念，文件本身不改写。

**7.4 的标题解析器还在**，但角色变了：图谱的覆盖检查用它解析同一批笔记，每个解析出的小节和例题都必须落进某个概念或列进 `ignored`，漏一个校验就失败。还没有图谱的课也继续用它显示（过渡期），导图按钮置灰。

**两种看法**：

- 导图：课程居中，章节在左右两侧切一刀分开——前几章在右、其余在左，切在两侧高度最接近的地方，所以阅读顺序是顺时针而不是左右交替。平衡只看到概念这一层，点开一个概念长出的要点不会让整章换边。布局是自写的整洁树（`mind-map-layout.js`，有单元测试：两侧平衡、互不重叠、父节点居中），节点尺寸先渲染再量，不猜文字宽度。先修只在选中概念时用虚线弧画出，不做常驻的关系网——连线稀疏时力导向图是一团散沙。
- 列表：章 → 概念两层。不再按日期分组，日期挪进概念卡。

**概念卡**两种模式共用：章节、标题、几号讲；四档按钮和依据（「9/26 自测 第2题 ✓」或「手动」）；一句话、关键公式、要点；先修 / 后续 / 相关可点；例题跳到课堂笔记原位；课堂笔记原文默认折叠、展开时才读文件；记忆线索。「连接知识点」按钮和「提炼记忆笔记」按钮都从概念卡上拿掉了：关系交给 agent，提炼入口留在学习成果页。

**掌握度**四档：待自评、需巩固、已理解、能应用。节点实底，形状和颜色一起区分（空心 / 叹号 / 半实心 / 实心），壁纸上也认得出字——令牌 `--os-mastery-*` 在 `contrast.js` 里按字 7:1、轮廓 3:1 把关，导图和概念卡在 `legibility.cjs` 的八种最坏背景上实测。地图显示每个概念最新的一条记录；手动修改和自测结果冲突时按时间取最新，两条都留着。7.4 存在 `data.json` 里的自评第一次读到图谱时按 `legacyKeys` 迁移，对不上的列出来，不静默丢弃。

## 周五自测

一周只有周一到周四有课，周五总结完让 agent 出题。本周有课堂笔记的每门课 10 题（约 6 概念 + 4 应用），每个被考的概念至少 2 题，题型单选为主，另有多选、判断、数值填空（带误差）。

- 一题一屏；选项按「周 / 课 / 题号」稳定打乱（避开出题人把答案放第一个的习惯，续做时顺序不变）；每答一题立即写作答文件。
- 「不确定」按没掌握算。「这题有问题」让这题不计分，结果页上也能标，标完掌握度重算（追加记录，最新的生效；某概念的题全被标掉时恢复到判分前的档位）。
- 只算第一次作答；「重做练习」不改档位。
- 换算：概念题有错或不确定 → 需巩固；概念题全对、应用题有错或没考 → 已理解；都对 → 能应用；只考了应用题：全对能应用、有错需巩固；没考到的维持原档位。

## 学习成果

学习成果是一份更加精简的课堂笔记，以看到内容就能联想知识点为目标。每份包含记忆提示、精简要点、关联概念（有图谱的课从图谱里选，存新 ID）和课堂来源。从学习成果页「提炼记忆笔记」新建，保存为「03 知识库/学习成果/课程/标题.md」，同名不覆盖。选中记忆笔记直接显示要点，点关联概念回到知识地图；需要回忆练习时加入间隔复习。

## 验证

- 单元测试：图谱校验（结构、先修成环、覆盖检查、公式抽查、ID 消失）、导图布局、掌握度记录、题库校验、判分与换算、选项乱序；四份真实图谱和 W39 题库都在测试里跑校验。
- 浏览器夹具（`HUB_ONLY=1 node tools/smoke-visual.cjs`）：真实静力学笔记与四份图谱；导图不重叠、点选、先修弧、拖动不误触、缩放、键盘、筛选、列表、过渡期；完整做一门自测（答对 / 答错 / 不确定）、结果页档位变化、标「有问题」重算、重做不改档位、续做、地图同步变色；四种宽度 × 深浅色不横向溢出；导图、概念卡、答题页的壁纸可读性。
- 夹具用纯文本代替 Obsidian 的 Markdown 渲染器，**公式渲染（MathJax）和平板手写笔拖动需要实机验收**。
