## 打开与切换

### 课堂笔记阅读

课堂笔记（`课堂笔记/` 下的笔记）右边有一条阅读栏，**编辑模式和阅读模式都在**，不用先切模式。正文一行约 40 个汉字，两种模式同一个行宽。

- **目录**：点一行跳过去，当前章节在左边细轨上亮一段蓝；有子标题的行悬停时出现折叠箭头。笔记开头那个 H1 是标题，不进目录。
- **题图跟随**：读一道题的推导时，这道题的图滚出屏幕顶上后会出现在目录下面的卡里；读到下一题就换成下一题的图。不想要：命令「课堂笔记：题图跟随（开 / 关）」。
- **钉住**：图、独立公式、表格、callout 悬停时右上角有「钉住」，点一下放进卡里，钉住的压过跟随。选中文字用命令「课堂笔记：把选中内容钉到阅读栏」或编辑模式的右键菜单；编辑模式没有选区时钉光标所在的那一块。卡上三个按钮：取消钉住、放大查看、回到原文。每篇笔记记住自己钉的那一块。
- **沉浸阅读**：栏顶的放大图标，或命令「课堂笔记：沉浸阅读（开 / 关）」。收起左右栏、藏掉功能区和状态栏，标签栏和页头移上去才出现；Esc 退出，左右栏还原。
- 栏顶的收起图标把栏收掉，右上角留一个打开它的按钮；命令「课堂笔记：显示 / 收起阅读栏」同理。拖栏的左边缘或聚焦后按方向键调宽度（260–560px）。笔记区窄于 980px 时栏收成右上角的按钮，点开是浮起来的抽屉，Esc 收回。

### 工作台导航

- 打开 CODEX专属 仓库后，点击左侧工作台图标，或在命令面板搜索「Codex 工作台：打开个人工作台」。
- 顶部是页面标题加一行这一页的状态（行动页报待办与逾期，热力页报本周分钟数）；右侧可添加任务或打开今日日记，左下角常驻快捷捕获。
- `Alt + 1` 今日 · `Alt + 2` 行动 · `Alt + 3` 学习 · `Alt + 4` 知识 · `Alt + 5` 回顾 · `Alt + 6` 课表 · `Alt + 7` 总结笔记。原有快捷键保持不变。
- 页内分段（大项目、教材、疑问、间隔复习、学习热力…）各自也是命令，只是不带默认快捷键。全部都能在快捷键设置里搜「Codex 工作台：切换到」改键。
- 侧栏七项，「总结笔记」位于学习与知识之间。进去之后标题下面那排小按钮是这一页的分段。窗口矮时导航区自己滚动，底部快速捕获始终可见。
- 挂件能放三个地方：**导航上**（品牌和导航之间）、**导航下**（导航和快速捕获之间那段空档）、**页头**（今日页标题那一行的右端，横着排）。挂件设置里每行右边那个按钮在三档之间轮换，按钮上的字就是它当前在哪。
- 默认：时间在导航上，每日一言和倒计日在导航下，天气在页头——天气一行就说完（`17° 多云 · 米兰`），塞进左栏得竖着摆成一张卡。空掉的挂件区会整块消失，不留空缝。
- 卡片有多透由「挂件设置 → 背景 → 玻璃浓度」决定：往左是极清透（壁纸透得更多），往右是全着色（更像实心卡片），默认 50%。拖到最左字也认得出——那一端是可读性闸门量过的。「背景图可见度」是另一件事，管的是卡片之外的页边能看见多少照片。
- 挂件设置入口：鼠标移进左栏，导航下方那块右下角会浮出「挂件设置」；或在命令面板搜「Codex 侧栏挂件」。窗口窄于 800px 或矮于 560px 时左栏那两块挂件区一起收起，把地方让给导航和快速捕获；页头那块只在窄于 800px 时收起——它是横排的一行，不占左栏高度，窗口再矮也不碍事。
- 窗口宽度不足 650px 时：今日页用「今日行动 / 专注与阅读」切换，知识页用「返回列表」回到笔记列表。

## 七个入口怎么用

| 入口 | 分段 | 常用动作 |
| --- | --- | --- |
| 总结笔记 | — | 自动关联课程文件夹中的课堂笔记；按日期分组；课程、日期及全文筛选；阅读全文并打开原文件编辑 |
| 今日 | — | 选定今日要务；查看今天安排与到期任务；开始或暂停专注；继续上次阅读 |
| 行动 | 行动清单 | 跨笔记检索任务；切换待办 / 今天 / 逾期 / 已完成；安排今天；勾选写回原文 |
| | 大项目 | 新建与管理项目；拆解子任务；挂载已有任务；编辑目标、下一步与截止日期 |
| 学习 | 课程 | 九门课的下一步与考试日期；打开关联教材；本周时长与待解疑问数 |
| | 教材 | 全库 PDF 检索；打开阅读，位置自动保存 |
| | 待解疑问 | 教材批注里标记的疑问；查看原文位置或转成行动 |
| 知识 | 笔记库 | 按路径或标签检索笔记；预览正文与双向链接；把笔记加入间隔复习 |
| | 间隔复习 | 到期队列与全部队列；先回忆、展开核对后评分 |
| 回顾 | 每日小结 | 选定某天查看时间审计：项目占比、任务工时、完成与未完、产出、洞察与阻力 |
| | 学习热力 | 近 12 周专注热力图；点击日期看当天时段，或切到「全部记录」按时间倒序浏览 |
| 课表 | — | 一周的上课网格；右上告诉你正在上哪节、下一节在哪个教室；翻周、点一节看教室楼栋与重叠 |

今日页的「下一步行动」按紧迫度排：逾期、今天截止、考试临近的课排在前面。课程的考试日期在课程分段里设置。

今日页右栏最上面是「今天的课」：一节一行，时间、课名、教室。正在上的那节整行上色并写着还剩几分钟，下一节标着几分钟后开始，上完的退成灰字。没课的日子只剩一行「下一节在什么时候」。点一行打开这门课今天的课堂笔记（没有就按模板新建，直接进编辑模式）；要看课表点卡头的「课表 →」。

课堂笔记一门课一个文件夹，放在 `03 知识库/我的课程/2026-27/课堂笔记/` 下，文件夹叫「代码 中文名」（和 `课程文件/` 一样），笔记叫「日期 课名」，例如 `060112 化工过程计算/2026-09-22 化工过程计算.md`——按名排序就是按时间。同一门课一天一篇，一天上两次的记在同一页。笔记开头写着日期、时间、教室和课程主页链接，下面是「课堂记录」「课后总结」两节。命令面板里「打开今天的课堂笔记」打开正在上（或下一节）那门课的笔记。

在课堂笔记里粘贴或拖进图片，图片存到这门课文件夹下的 `附件/`，名字是「日期 课名 时分秒」，正文插入嵌入链接。粘贴带 `\( \)`、`\[ \]` 或光着的 `\begin{align}…\end{align}` 的 LaTeX，会自动改成 Obsidian 认的 `$ … $` / `$$ … $$`；已经是 `$` 的公式、代码块和 `\\[4pt]` 这种换行间距不动。别的笔记里要改，用命令「把当前笔记的公式改成 Obsidian 写法」。`\dv{f}{x}`、`\pdv{f}{x}`、`\abs{x}`、`\norm{v}`、`\vb{F}`、`\R`、`\dd`、`\degC` 这些常用宏全库都能用。

每天第一次打开工作台时，今天有课的每门课会在「下一步行动」里挂一条「总结笔记 · 课名 · 月-日」：P2、一个番茄、分类「课堂笔记」，不挂项目。没做完的照常留到第二天；删掉的不会再冒出来。

课表的数据就是 [[Polimi 2026-27 第一学期课表]] 那篇笔记——frontmatter 写着 `type: timetable`，工作台读的是里面「星期 | 时间 | 课程 | 教室 | 起始日期 | 结束日期」那张表，以及教室位置表和教师表。调课或换教室时直接改那张表，工作台下一次刷新就跟着变，不另存一份。一学期一篇：今天落在哪篇的学期里就用哪篇。结束日期标着「⚠ 待核实」的行（比如静力学官方写的 2027-12-20）按本学期其他课程最晚的结束日截断，不会画进下个学期。

今日页中间栏底部的「快捷闪念」是不会打断当前学习的临时草稿：输入内容会自动保存在工作台数据里，刷新或重启后仍在。粘贴带 `\( \)` 或 `\[ \]` 定界符的 LaTeX 时，会像学习面板的公式速记一样转换成 Obsidian Markdown，并在下方实时排版。点击「写入今日日记」或按 `Ctrl/Cmd + Enter`，内容会以带时间的小节归档到当天的「随手记录」；确认写入成功后才清空草稿。

## 大项目

在“大项目”页可以打开项目笔记、添加或挂载子任务，也可以点击“编辑项目”修改项目名称、目标、下一步和截止日期。点击“删除项目”后，项目文件会进入 Obsidian 回收站；项目重命名会同步更新任务上的项目引用。

## 间隔复习收两种东西

整篇笔记：在知识页选中一篇，点「加入复习」。

单张卡片：在读 PDF 时点卡片右上角的 `···`，选「加入间隔复习」。复习时展开的是引文加你的批注，评分之后可以一键跳回它所在的那一页。值得反复看的往往是某一个公式、某一处卡壳，而不是整本书的笔记。

## 两个容易搞混的词

- **今日要务**：今天最值得完成的那一件事。在任务行点「设为今日要务」，或在今日页的 ONE THING 卡片里选。它会写进当天日记的 frontmatter（`focus_task_id`）和正文的「今天最重要的一件事」。
- **开始专注**：启动番茄钟计时。任务行、ONE THING 卡片和专注面板上的「开始专注」是同一件事，区别只在于用哪个任务计时。

设为今日要务不会自动开始计时；开始专注也不会改变今日要务。

## 联网说明

**完全离线。** 任务、专注、PDF、复习、日记、课程，没有一处访问网络。

6.1 之前顶栏有一个天气组件，是全项目唯一的联网行为（每 30 分钟向 `api.open-meteo.com` 发送你所在城市的经纬度）。它占着页头最显眼的位置，而对「今天学什么」没有任何帮助，所以删掉了。旧的天气设置会在下次保存时自动从 data.json 里清除。

## 常见问题

- **打不开 PDF**：确认 `codex-study` 已启用；学习页只打开阅读材料，不会自动开始计时。
- **计时没有自动开始**：需显式点击「开始专注」或使用 Codex 专注命令；关闭工作台后计时仍由 `codex-focus` 独立运行和结算。
- **行动页看不到某条任务**：任务必须位于收件箱、项目、知识库、创作、日记或 [[今日任务]]，且不能位于「归档」「模板」或 `08 插件开发`；代码围栏中的示例任务也会被忽略。
- **勾选失败**：说明来源行已被并发修改或存在重名歧义；刷新后重试即可，索引不会覆盖原文。
- **复习数据在哪**：评分、到期与历史保存在 `codex-recall` 自己的 data.json；移出复习只删除调度，不删除笔记。
- **左栏挂件不见了**：先看窗口尺寸——窄于 800px 或矮于 560px 是故意收起的。尺寸够还没有，就是 `codex-widgets` 没启用；停用它左栏回到 6.3 的样子，工作台其余部分不受影响。
- **倒计日为什么要自己填**：挂件不读任务的截止日期，也不读课程的考试日期。左栏那块是装饰性的，不该因为 `codex-capture` 停用就空掉半块。真正按紧迫度排序的是今日页的「下一步行动」，那里用的才是任务和课程的真实日期。
- **背景那张图是哪来的**：Windows 桌面聚焦的缓存（`%LOCALAPPDATA%\Packages\MicrosoftWindows.Client.CBS_*\LocalCache\Microsoft\IrisService`），每天换一张，只读不写。它压在一层遮罩底下只当纹理——正文该多清楚还是多清楚。不想要就在挂件设置的「背景」一节关掉；想立刻换一张，那里也有按钮。
- **背景没有图**：说明读不到聚焦缓存——没开 Windows 聚焦、不是 Windows、或者目录被清过。这是正常路径，界面会安静地退回原来的渐变，不报错。
- **天气取不到**：挂件会继续显示上一次的值——显示一小时前的气温，比显示一个错误提示有用。想立刻重试用命令「Codex 侧栏挂件：立即刷新天气」。
- **旧插件是否还要保留**：不需要。只启用 `codex-workbench`、`codex-capture`、`codex-focus`、`codex-study`、`codex-recall`、`codex-widgets` 六个；`codex-iteration` 已在 6.0 删除，版本日志改由构建生成，入口是命令「Codex 工作台：打开版本迭代」。

## 数据位置

| 内容 | 位置 |
| --- | --- |
| 任务 | 原 Markdown 笔记：收件箱 / 项目 / 知识库 / 创作 / 日记，以及 [[今日任务]] |
| 专注计时与历史 | `.obsidian/plugins/codex-focus/data.json` |
| PDF 阅读位置、批注与疑问 | `.obsidian/plugins/codex-study/data.json` 与教材笔记 |
| 复习调度与评分历史 | `.obsidian/plugins/codex-recall/data.json` |
| 挂件设置、倒计日与天气缓存 | `.obsidian/plugins/codex-widgets/data.json` |
| 工作台偏好、今日要务与快捷闪念草稿 | `.obsidian/plugins/codex-workbench/data.json`；要务与主动归档的闪念同步写入当天日记正文 |
| 课表 | `type: timetable` 的笔记（当前是 [[Polimi 2026-27 第一学期课表]]），工作台只读不写 |
| 课程关联与考试日期 | `codex-workbench` 偏好中的 `courses`，并同步到课程笔记的「工作台课程信息」区块 |

## 维护与回退

- 在 `08 插件开发` 目录运行 `node tools/verify.js`，再运行 `node tools/deploy.js`；也可双击 `08 插件开发/deploy-plugin.cmd`。
- 只更新一个插件：`node tools/verify.js --plugin codex-recall`、`node tools/deploy.js --plugin codex-recall`。
- 只同步本页：`node tools/sync-docs.js`（不会改动插件与 data.json）。
- 部署只复制 `main.js`、`manifest.json`、`styles.css`，不会覆盖 data.json。
- 禁用对应插件即可停用该模块，Markdown 笔记仍可直接阅读；[[主面板]] 是无需插件的导航页。
- 退回某个版本：在 `08 插件开发` 目录 `git checkout v<版本> && node tools/deploy.js`。发布流程见 `docs/发布流程.md`。
