# 知识图谱与出题规范

agent 维护知识地图、出周五自测题时照这份规范做。插件只读图谱和题库、只写掌握度，判分和换算都在本地；背景和取舍见 [知识地图导图与周五自测方案](知识地图导图与周五自测方案.md)。

写完一律运行（工作目录 `08 插件开发`）：

```
node tools/check-knowledge-graph.cjs
node tools/check-quiz.cjs
```

校验不过的文件插件不会加载，失败信息会指出是哪门课、哪个概念、哪一题。两份检查都在 `npm test` 里。

## 文件与分工

| 文件 | 谁写 | 内容 |
| --- | --- | --- |
| `03 知识库/知识地图/<代码> <课程名>.json` | agent | 一门课的概念图谱 |
| `03 知识库/周五自测/<ISO 周>.json` | agent | 一周的题库 |
| `03 知识库/知识地图/掌握度.json` | 插件 | 掌握度记录，只追加；agent 只读 |
| `03 知识库/周五自测/<ISO 周> 作答.json` | 插件 | 作答记录；agent 出题前读取「这题有问题」 |

课堂笔记只读不改。笔记本身的写法仍按 `L-OS专属/AGENTS.md`。

## 一、概念图谱

### 格式

```json
{
  "course": "057274",
  "title": "静力学与结构力学",
  "updatedAt": "2026-09-26T20:00:00+02:00",
  "skeletonSource": "课程文件/057274 静力学与结构力学/01 课件/Introduzione al corso.pdf",
  "notes": [{ "path": "03 知识库/…/2026-09-22 静力学与结构力学.md", "integratedAt": "2026-09-26T20:00:00+02:00" }],
  "chapters": [{ "id": "ch01", "order": 1, "title": "质点静力学", "status": "learned" }],
  "concepts": [{
    "id": "c-force-composition",
    "chapter": "ch01",
    "title": "力的合成与分解",
    "firstTaught": "2026-09-14",
    "summary": "一句话说清这个概念。",
    "formulas": ["R^2=P^2+Q^2-2PQ\\cos\\hat B"],
    "points": ["要点一", "要点二"],
    "prereqs": ["c-force-vector"],
    "related": [],
    "sources": [{ "path": "03 知识库/…/2026-09-22 静力学与结构力学.md", "heading": "1.2 加法的三个法则" }],
    "examples": [{ "path": "…", "heading": "1.5 例 1：两个力求合力（余弦 + 正弦定理）", "title": "两个力求合力" }],
    "legacyKeys": ["057274:%E5%90%91%E9%87%8F…"],
    "retired": false
  }],
  "ignored": [{ "path": "…", "heading": "2 · 例题逐题解析", "reason": "例题容器，题已挂到概念" }]
}
```

- `chapters[].status`：`learned` 已讲；`planned` 未讲，学期初按大纲铺好。
- `sources` / `examples` 的 `heading` 照抄笔记里的标题原文（含编号），插件用 `路径#标题` 跳转。
- `firstTaught` 是这个概念第一次在课上讲的日期（板书日期，不是笔记文件日期）。
- `legacyKeys` 是 7.4 标题解析器给出的旧键（`课程代码:` + 小写标题的 `encodeURIComponent`），用来迁移旧自评和学习成果里的 `concepts`。

### 规则

1. **概念是能单独出题考的单位。**一门课几次课下来十几到二十个概念；原笔记的三四级小节变成概念的 `points`。例题不单独成概念，挂到它考察的概念的 `examples` 下。
2. **ID 固定。**格式 `c-` 加英文短语（小写、连字符）。一个 ID 只指一个概念，永不复用；改名只改 `title`。合并或删除时标 `retired: true`，不从文件里删，历史测验记录才挂得上。
3. **有出处。**每个未退役概念至少一处 `sources`。`formulas` 必须照抄来源小节里的 LaTeX（去掉空白后能在原文里找到），不许自己编或改写记号；公式不带 `$`。
4. **不遗漏。**用 7.4 的标题规则解析同一批笔记（学习指引整块跳过、例题挂到概念、标题去编号日期页码），解析出的每个知识点和每道例题，要么进某个概念的 `sources` / `examples`，要么旧键进某个 `legacyKeys`，要么列进 `ignored` 并写明原因。
5. **先修不成环**，`prereqs` / `related` 只指向同一门课里未退役的概念，不指向自己。`related` 不重复 `prereqs` 里已有的。
6. **只增量更新。**只处理 `notes` 里没有、或文件修改时间晚于 `integratedAt` 的笔记；处理完更新 `integratedAt` 和顶层 `updatedAt`。已有概念只补 `points`、`sources`、`examples`，不改 ID。
7. **分章依据。**优先课程大纲（如 `Introduzione al corso.pdf` 的 Temi trattati）或课程日历、关联教材目录；都没有就按讲授顺序，只铺已学部分。在 `skeletonSource` 里写明依据。
8. **一个旧键只映射一个概念**，一个来源小节只归一个概念。容器小节（只有标题、正文在下面几节里）也要归属：旧键放进它主要内容所在的那个概念。
9. **摘要写给自己看**：`summary` 一句话、不超过 60 字；`points` 每条一句，写条件和易错点，不抄推导。

### 校验脚本查什么

- 结构与必填字段；概念 ID、章节 ID 唯一；章节状态合法；`firstTaught` 是日期。
- `sources`、`examples` 指向的文件存在，标题在文件里存在。
- `prereqs`、`related` 指向存在且未退役的概念；先修图无环。
- 覆盖检查（规则 4）。
- 公式抽查（规则 3）。
- 每个旧键只出现在一个概念里。

## 二、周五自测题库

### 什么时候出

一周只有周一到周四有课。用户周五总结完本周笔记后，手动让 agent 出题；不走定时任务。出题前先把本周新笔记整理进图谱（上一节），再读上一周的作答文件，避开被标成「这题有问题」的题。

### 范围与配比

- **本周有课堂笔记的每门课都考**，那周没课的课不考。每门**正好 10 题**。
- 每门约 **6 道概念题 + 4 道应用题**（`level`：`concept` / `application`），它决定换算规则。
- **每个被考的概念至少 2 题**，所以每门每周约测 5 个概念。一题可以挂多个概念，但主要考一个。
- 抽样优先级：本周新学（`firstTaught` 在本周）的核心概念 → 仍是「需巩固」的 → 按间隔复查的「已理解」。没考到的维持原档位，覆盖靠跨周累积。

### 题型

| type | 用途 | answer |
| --- | --- | --- |
| `single` | 单选，主力题型 | `[下标]`，从 0 数起 |
| `multiple` | 多选，至少两个正确项 | `[下标, …]`，必须全选对 |
| `truefalse` | 判断一个常见误解 | `true` / `false`，不写 options |
| `numeric` | 数值填空 | `{"value": 3.333, "tolerance": 0.01}`（相对误差）或 `{"value": 0, "abs": 0.05}`（绝对误差）；必须写 `unit`，无量纲写 `"—"` |

不出简答和推导：它们要 AI 批改，破坏离线。选项 3–6 个。「不确定」由插件自动加，题库里不写。

### 质量规则

1. **干扰项用典型错误构造**：漏乘 1/2、符号取反、起算端弄反、单位没换、把相关概念的结论套过来。不用明显荒谬的选项。
2. **插件会打乱选项顺序**：选项和解析里不能出现「以上都对」「第二个选项」「A/B」这类依赖位置的说法。
3. **计算题先用脚本实算**（MATLAB 代码题用本机 MATLAB 实跑），再出选项；解析写出算式和结果。
4. **每题有解析和原文出处**：`source` 指向课堂笔记里真实存在的标题（照抄原文，含编号）。解析说明为什么对，以及最常见的错选错在哪。
5. **不照抄笔记里的例题数字**：换数字、换问法，考的是会不会用，不是记没记住那道题。
6. **配图只引用课堂笔记里已有的附件**（`![[文件名]]`），不自己画受力图。
7. 公式用 `$…$` / `$$…$$`，定界符成对；代码用 Markdown 代码块。
8. 风格参考 `课程文件/<课>/03 真题`。

### 格式

`03 知识库/周五自测/2026-W39.json`（ISO 周）：

```json
{
  "week": "2026-W39",
  "createdAt": "2026-09-26T22:45:00+02:00",
  "courses": [
    { "course": "057274", "questions": [
      { "id": "q01", "concepts": ["c-distributed-load"], "level": "concept", "type": "single",
        "stem": "…", "options": ["…", "…", "…", "…"], "answer": [0],
        "explanation": "…", "source": { "path": "…", "heading": "3.2 从零线性增大的三角形荷载" } }
    ] }
  ]
}
```

### 判分与换算（插件做，写在这里是为了出题时心里有数）

按周、按概念，只看**首次作答**、没被标成「这题有问题」的题：

| 作答情况 | 判定 |
| --- | --- |
| 有概念题答错，或选了「不确定」 | 需巩固 |
| 概念题全对，应用题有错或没考应用题 | 已理解 |
| 概念题和应用题都对 | 能应用 |
| 只考了应用题：全对 / 有错 | 能应用 / 需巩固 |
| 本周没考到 | 维持原档位 |

所以一个概念只出两道概念题，最多只能测到「已理解」；想测到「能应用」要配应用题。

### 校验脚本查什么

`tools/check-quiz.cjs`：每门 10 题；题号唯一；题型与答案格式；答案下标在选项范围内；选项不重复；概念存在于图谱且未退役；每个被考概念至少 2 题；出处标题存在；配图存在；公式定界符成对。
