# 设计系统

> 活文档。`shared/tokens.css` 是唯一定义处，`tools/build.js` 构建时把它内联到每个插件 `styles.css` 的最前面；插件样式只消费 `var(--os-*)`。

这次是真的唯一。6.0 之前 `design/00-tokens.css` 也写着「唯一真相源，禁止再写具体色值」，但它被零个文件引用，副本躺在 `.obsidian/snippets/` 而 `appearance.json` 的 `enabledCssSnippets` 是空的——从未启用。声明唯一没有用，得有机制。现在的机制是构建内联加 `tools/check.js` 的色值提示。

## 对比度闸门

`tools/contrast.js` 对两套主题逐条校验 18 项关系，不达标直接构建失败。这类判断眼睛不可靠——起草 6.1 方案时，我两次凭截图判断颜色都判错了（深色主按钮、任务标题），像素采样才给出正确答案。

| 关系 | 下限 | 挡住的是 |
| --- | --- | --- |
| 卡片 / 页面底 | 1.25 | 6.0 时是 1.11，卡片和背景等于没差 |
| 次级面 / 页面底 | 1.12 | 6.0 时是 1.09 |
| 分隔线 / 卡片 | 1.80 | 6.0 时是 1.43，而所有分区都靠这条线 |
| 正文、次要文字、强调色、危险色对各自底色 | 4.50 | 次要文字铺在 soft 卡片上曾是 4.18，低于 AA |

6.1 只动明度、不动色相：页面底 `#f4eee5 → #e8e1d7`，次级面 `#eee4d7 → #dcd4c6`，分隔线 `#ded2c3 → #c6b9a8`，次要文字 `#7d685b → #6a5749`。文字的颜色一直是对的，塌掉的是面与面之间的明度差。

## 令牌

定义在 `:root` 与 `body.theme-dark` 上。自定义属性会继承，所以五个插件都能用，单独启用其中一个也在。

| 组 | 令牌 |
| --- | --- |
| 底色 | `--os-bg` `--os-paper` `--os-soft` `--os-rail` |
| 线与焦点 | `--os-line` `--os-focus` |
| 文字 | `--os-ink` `--os-muted` |
| 强调 | `--os-accent` `--os-accent-hover` `--os-danger` |
| 字阶 | `--fs-display` `--fs-title` `--fs-body` `--fs-meta` `--fs-timer` |
| 学习热力 | `--os-heat-0` … `--os-heat-4` |
| 标注色 | `--os-mark-{yellow,coral,mint,blue,purple}` 及 `-text` / `-chip` 变体 |

字阶只有四级加一个计时器专用展示号。5.4.0 之前散落 22 种字号，差 1px 的相邻值到处都是——密度上去了但层次没建立。工作台在 `@container` 查询里按尺寸重定义这几个字号，改的是 `.os-root`，只影响工作台视图内部，不回头影响别的插件。

## 风格

暖纸底、Georgia 衬线标题、四级字阶。6.0 没有重做视觉——重做视觉属于新功能，而 6.0 是一次可发布性迭代。

## 未决：标注色的三套值

同一个命名颜色在三处用三个值：

| 命名 | 高亮线 | 文字标签 | 调色按钮 |
| --- | --- | --- | --- |
| blue | `#3974a6` | `#3974a6` | `#78bdec` |
| purple | `#8d6bc0` | `#7653a6` | `#b49add` |
| coral | `#e46f61` | `#b84a45` | `#ee8a7c` |

各有各的道理：PDF 上的高亮线要够深才看得见，卡片上的文字要更深才够对比度，按钮要更浅才不抢眼。但 blue 的文字和高亮同值、purple 却不同值，说明这不是有意设计的三层，是分三次写出来的。

6.0 只把它们收成命名令牌，**一个值都没改**。三套值是否真该存在、要不要按明度算法从一个基色派生，留给 6.1 决定。在那之前，改任何一个都只改 `shared/tokens.css`。

同样未决的还有工作台 `.os-audit-row progress` 的 `accent-color:#94745d`，目前是全项目唯一一个没收进令牌的品牌色，`check.js` 每次构建都会点名它。

## 已经废掉的东西

- 夜航蓝 Night Voyage（`--cw-accent:#3E6FA8` 那套）：从 3.1 起就没在跑，6.0 删除了 `design/00-tokens.css` 与那份未启用的 snippet。
- `--cw-*` 命名空间：codex-study 曾在 `.cw-study-host` 上自定义 `--cw-accent:#ad5739`，而同插件的弹窗写 `#a34b2d`,一个插件两个橙；study 也完全没有深色分支，夜间读 PDF 时面板仍是浅色。6.0 统一到 `--os-*` 之后两件事一起解决。
