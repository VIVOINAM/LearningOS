# codex-widgets

工作台左栏的可配置挂件：时间、每日一言、倒计日、天气。

挂件能去三个地方：左栏导航上方、左栏导航下方、今日页标题那一行的右端。默认时间在导航上方（左栏顶部是视线第一个落点，而时间是一眼扫过去就要读到的东西），每日一言和倒计日在导航下方，天气在页头——它一行就说完，塞进左栏得竖着摆成一张 85px 的卡。全部能在设置里改。

左栏在 6.3 是这样的：`.os-nav{flex:1}` 把导航撑开，`.os-rail-foot{margin-top:auto}` 把底部按钮压到底，中间那段 196px 宽、将近 400px 高的空白是布局要求它空着，不是没来得及填。这个插件把那段空白变成内容。

## 对外接口

```js
const widgets = app.plugins.getPlugin('codex-widgets');
const mount = widgets?.renderRail?.(hostElement, {slot: 'top'}); // 返回 {destroy(), paint()}
mount?.destroy();                                                 // 调用方销毁时必须调
```

`slot` 是 `'top'`、`'bottom'` 或 `'header'`。调用方提供地方，哪个挂件去哪一块由用户在设置里定。

`header` 槽走的是另一套渲染：页头只有一行高，竖着摆的卡片放不进去，所以挂件可以另外提供一个横排版本（`inline_<id>`）；没提供的就退回卡片版——宁可在页头里长得像张小卡，也不要什么都不画。目前只有天气写了横排版。

只有 `renderRail` 一个入口。插件不知道工作台的存在，工作台也不知道挂件长什么样——工作台只给三块 `div` 和一个生命周期。停用本插件，左栏回到 6.3 的样子，工作台不少任何功能。

走秒由插件自己的一个 interval 驱动，喂所有挂载点；工作台反复 `refresh()` 不会留下一串还在跑的旧计时器。挂载点所在的节点脱离文档后会在下一拍自我销毁。

## 天气是唯一一处联网

其余三个挂件零网络代码。天气默认关闭，填了经纬度才会发请求：

- 目标 `api.open-meteo.com`，无需 API key，无账号
- 只带经纬度，降到两位小数（约 1 公里）再出门，见 `core.roundCoord`
- 不带任何标识，不读 Vault 里的任何内容
- 取不到就继续显示上一次的缓存值。显示一小时前的气温，比显示一个错误提示有用

学习资料、任务、进度、复习记录仍然全部留在本地——那是「完全离线」这句话所指的东西，这个插件一个字节都不碰。

## 设置

左栏挂件区右下角的齿轮，或命令面板的「侧栏挂件设置」。每一项改完立即落盘，所以弹窗里没有「保存」。

倒计日是自己填的列表（名称 + 日期），和任务系统解耦：本插件单独启用也能用。过去的日期不会消失，显示成「已过 N 天」——纪念日和截止日用的是同一个挂件。

每日一言按日期散列取，不是随机：同一天里刷新多少次都是同一句。

## 独立验证与部署

```powershell
node tools/verify.js --plugin codex-widgets
node tools/deploy.js --plugin codex-widgets
```

从上级开发目录运行。`core/widgets.js` 不碰 DOM 也不碰网络，跨年、夏令时、脏数据、接口返回垃圾这些情况全部在 `tests/widgets.test.js` 里跑，不靠开着 Obsidian 盯屏幕。
